# BUILD 010 — FIX 2: Rolling Branch Shortage Counter

## Purpose
Implements the confirmed operational rule for Branch Shortage Counter:

- `Added` = fresh shortage generated by Till Balancing SHORT events for the selected business date.
- `Amount Owed` = current outstanding shortage after all payments recorded up to the selected date.
- `Paid Off` = payments recorded on the selected business date.
- `Balance` = current outstanding shortage; therefore it equals the new `Amount Owed` after a payment.

Example:
- Starting shortage: UGX 10,000
- Payment today: UGX 500
- Amount Owed: UGX 9,500
- Paid Off: UGX 500
- Balance: UGX 9,500

If a later shortage of UGX 1,000 is added while UGX 9,500 remains outstanding:
- Amount Owed: UGX 10,500
- Added: UGX 1,000
- Balance: UGX 10,500

Historical shortage and payment rows remain stored; the rolling position is calculated rather than destroying history.
