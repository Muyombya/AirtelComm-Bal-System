# Till Balancing — confirmed foundation

At a balancing event, an attendant counts physical cash and checks the current terminal/service float balances.

Actual Till Capital = Total Cash + Total Float

Difference = Actual Till Capital - Till Operating Capital

Result:
- Difference = 0 → BALANCED
- Difference < 0 → SHORTAGE
- Difference > 0 → EXCESS

A balancing event is retained as a historical event with its date/time and Till identity.
